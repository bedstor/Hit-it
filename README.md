# Turtle Arcade Game 🐢🎮

Простая, но увлекательная аркадная игра, демонстрирующая использование ООП (объектно-ориентированного программирования) в Python.

## 🚀 Особенности игры
- **Классы и Наследование:** Вся логика игровых объектов вынесена в класс `Sprite`, наследуемый от `Turtle`.
- **ИИ враги:** Прописан алгоритм автоматического патрулирования между заданными точками.
- **Система коллизий:** Реализована проверка столкновений игрока с врагами и финишем через расчет дистанции.
- **Уровни:** Для победы нужно трижды дойти до финиша, уворачиваясь от красных квадратов.
- **Счетчик:** Визуальное отображение текущего счета прямо на игровом поле.

## ⌨️ Управление
- **Стрелки на клавиатуре:** Перемещение игрока (оранжевый круг).
- **Цель:** Дойти до зеленого треугольника 3 раза.

## 🛠 Технические навыки
- Использование классов (`class`) и методов.
- Обработка событий клавиатуры (`onkey`).
- Игровой цикл `while` с проверкой условий победы и поражения.

## 🔧 Запуск
```bash
python Hit_it.py
```
